## Setup (once)

1. **Python (includes pip)** — Windows: install from [python.org/downloads](https://www.python.org/downloads/) and tick **"Add python.exe to PATH"**. Mac: install from [python.org/downloads/macos](https://www.python.org/downloads/macos/).
2. **Git** — download and install from [git-scm.com/downloads](https://git-scm.com/downloads).
3. **VS Code** — download and install from [code.visualstudio.com](https://code.visualstudio.com/). Then sign in to GitHub (Accounts icon, bottom-left).

## Upload your notes (VS Code)

1. **Clone:** open VS Code → `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`) → type `Git: Clone` → paste the repo link → Open.
2. **Add:** drag your notes file into the subject folder, e.g. `EC3363-Signals-Systems/notes/`. Name it `Unit-<n>-<topic>-<your-name>.md` (PDFs are fine too).
3. **Commit:** open **Source Control** (`Ctrl+Shift+G`) → type a message like `Add Unit 2 notes - EC3363` → click **Commit**.
4. **Push:** click **Sync Changes**.

Done. `add` = pick your file, `commit` = save it with a message, `push` = send it to GitHub.
